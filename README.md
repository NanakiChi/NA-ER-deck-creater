# NivelArena デッキビルダー（エターナルリターン）

[NivelArena](http://nivelarena.jp/) 公式サイトのカードリスト（エターナルリターンIP、全146枚）を元にした、ローカルで動くデッキ構築ツールです。

## 使い方

1. このフォルダで簡易サーバーを起動します（Python が必要です）。

```bash
python -m http.server 8765
```

2. ブラウザで [http://localhost:8765/](http://localhost:8765/) を開きます。

## 機能

- カード一覧の閲覧・検索（カード名/効果テキスト）・絞り込み（属性・種類・レアリティ・コスト）
- カードクリックで詳細（効果テキスト・ステータス・収録商品・別イラスト違い）を表示
- リーダー選択、第2属性の選択（リーダー欄のチップで選択。リーダー本来の属性＋もう1色のみデッキに入れられます）
- デッキへのカード追加/削除（+1 ボタン or 詳細画面）
- 公式ルールに基づくデッキ検証を自動表示
  - リーダー1枚 + カード40枚 = 合計41枚
  - カードの属性は「リーダーの属性」または「選択した第2属性」のいずれかのみ（誓約テキストに基づく2色構成ルール）
  - 識別番号が同じカードは最大3枚（レアリティ違いの再録カードも合算）
  - トリガー効果を持つカードはデッキ全体で最大8枚（上記3枚制限とは別枠のルール）
- デッキはブラウザの localStorage に自動保存（次回開いたときも復元）
- デッキのテキストエクスポート／インポート（クリップボードにコピー、貼り付けで復元）

## データ更新について

`scripts/download_assets.py` と `scripts/process_cards.py` は、NivelArena公式サイトから取得したデータを元に
`data/cards_raw.json` → `data/cards.json` を生成するためのスクリプトです（今回はブラウザ経由で取得済みのデータを使用）。
新弾が追加されたら、同様の手順でカード情報とサムネイル画像を再取得し、`data/cards.json` を更新してください。

## フォルダ構成

```
index.html          メイン画面
css/style.css        スタイル
js/app.js            アプリロジック（フィルター・デッキ構築・検証）
data/cards.json       カードデータ（表示用）
data/cards_raw.json    スクレイピングした生データ
images/cards/         カードサムネイル画像（wr_id.png）
images/icons/         効果テキスト内アイコン画像
scripts/              データ取得・加工スクリプト
```
